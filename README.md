# python_quality_gate
Production-ready validation pipeline using Pandas &amp; Pydantic. Ingests Excel spreadsheets, maps column headers to strongly typed schemas, catches duplicate primary keys, executes complex cross-field business logic, and outputs human-readable error reports with exact row numbers. Zero-trust database injection.

# 🏛️ Class Naming ConventionStyle

## PascalCase (also known as CapWords).
#### Rule: Capitalize the first letter of every word.
#### Do not use underscores.
#### Examples: class DataProcessor:, class UserAccount:, class CloudStorageClient:. 
* [1] (https://stackoverflow.com/questions/5978557/association-between-naming-classes-and-naming-their-files-in-python-convention), 
* [2] (https://www.youtube.com/watch?v=WUuZHZSif90&t=292), 
* [3] (https://realpython.com/python-pep8/)
# 📄 File (Module) Naming ConventionStyle

## snake_case.
#### Rule: All letters must be lowercase. 
#### Separate words with underscores to improve readability. 
#### Keep names relatively short.
#### Examples: data_processor.py, user_account.py, cloud_storage.py. 
* [1] (https://softwareengineering.stackexchange.com/questions/308972/python-file-naming-convention),
